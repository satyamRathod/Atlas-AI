# Atlas AI

Enterprise-grade AI platform built from scratch using modern TypeScript, Node.js, Retrieval-Augmented Generation (RAG), LangChain, LangGraph, and cloud-native architecture.

> **Status:** 🚧 Work in Progress

## Goals

- Learn LLM fundamentals
- Build a production-ready backend
- Implement RAG from scratch
- Integrate LangChain & LangGraph
- Focus on security, observability, and scalability
- Deploy using Docker & Kubernetes
